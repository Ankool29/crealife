# Graphismes de CreaLife

Comme dans *Creatures 3*, la créature et le décor sont modélisés en 3D puis
rendus en images (sprites, couches de décor). Les scripts sont exécutés avec le
module Python de Blender (`pip install bpy`, Python 3.11).

```sh
python art/blender/creature.py <dossier> test     # rendu test de la créature
python art/blender/background.py <dossier> test   # rendu test du décor
```

Travail en cours : direction artistique à valider avant la génération
des animations et l'intégration dans le jeu.
